# Levon Kostandyan — personal site

Static HTML, CSS and a little JavaScript. The pages are generated by a small
Python script and committed, so GitHub Pages just publishes the folder.

## Structure

```
content/works.json         Case studies (text, images, tags, role)
content/experience.json    Roles and dates (from the CV)
content/skills.json        Skills and languages (from the CV)
tools/build.py             Page templates; writes all the HTML below
index.html                 Home
about/index.html           About, experience, skills
works/index.html           Works grid
works/<project>/index.html Case studies
contact/index.html         Contact
css/style.css              All styles (colours, type, motion settings at the top)
js/site.js                 Scroll reveals, mobile menu, footer year
images/                    Case study images (JPEG)
assets/                    CV, portrait, favicon, link preview image
```

## Editing

Change the JSON in `content/` (or the templates in `tools/build.py`), then:

```bash
python3 tools/build.py
```

## Preview locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy

GitHub Pages publishes `main` from the repository root at https://kostandyan.me
(Settings → Pages → Deploy from a branch → `main` / root). `CNAME` holds the
domain and `.nojekyll` makes Pages serve the files as they are. Every push to
`main` goes live within a minute or two.

DNS (GoDaddy): four `A` records for `@` pointing to 185.199.108.153,
185.199.109.153, 185.199.110.153 and 185.199.111.153, and a `CNAME` for `www`
pointing to `levon-isaa.github.io`.
